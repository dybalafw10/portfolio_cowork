# Paperlogy 웹폰트
사용자가 지정한 fonts-archive/Paperlogy 배포본과 동일한 저장소의 원본 WOFF2를 수정 없이 자체 호스팅합니다.
출처: https://github.com/fonts-archive/Paperlogy/tree/d73efc3cd471a7faf198f39b1783b14da13dd7c4
원래 서브셋 CSS: https://cdn.jsdelivr.net/gh/fonts-archive/Paperlogy/subsets/Paperlogy-dynamic-subset.css

클라우드 Chromium의 CDN 인증서 신뢰 문제 및 외부 CDN 장애에 영향받지 않도록 필요한 400/500/600/700/800만 포함합니다. SIL OFL 1.1 라이선스는 폰트 내부 name table에서 확인했습니다. 저작권 표기와 OFL 원문은 OFL.txt에 포함합니다. 원본 글꼴 파일과 저작권은 변경하지 않습니다.
